# 性能測定の記録

保存方式や索引方式を変えたときに、同じハーネスで変更前と変更後を比較した記録です。
どれもローカルの workerd で、公式の Vitest Workers 統合と、ローカルの SQLite DO と R2 の binding を使って測定しています。
R2 の各操作には人工的な遅延を加えていますが、本番 R2 の遅延、スループット、費用、Workers の CPU 上限は測定していません。

| 記録 | 対象の変更 | 内容 |
| --- | --- | --- |
| [チェックポイント](checkpoint.md) | b6c1295 | 復元用チェックポイントをバックグラウンドの保守に移したことによる、応答時間と R2 操作数の変化 |
| [共有索引と保存](shared-index.md) | 64b8fe5 | 共有転置索引、本文と履歴の単一オブジェクト化、保守 alarm の交互実行による、検索、保存、索引構築の変化 |

どちらの測定も通常のテストには含まれず、`pnpm test:performance` で実行します。
結果は標準出力に `PERFORMANCE_JSON` または `SHARED_PERFORMANCE_JSON` で始まる 1 行の JSON として出力され、このディレクトリの `*-before.json` と `*-after.json` はその保存です。
